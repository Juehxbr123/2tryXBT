Переводчик через Google Translate (deep-translator)
"""
import logging
from typing import Optional
import asyncio

logger = logging.getLogger(__name__)


async def translate_to_russian(text: str) -> Optional[str]:
    if not text or len(text.strip()) < 5:
        return None
    try:
        from deep_translator import GoogleTranslator
        loop = asyncio.get_event_loop()
        result = await loop.run_in_executor(
            None,
            lambda: GoogleTranslator(source='auto', target='ru').translate(text[:4500])
        )
        if result and result != text:
            return result
        return None
    except Exception as e:
        logger.warning(f"Translation error: {e}")
        return None

Twitter→Telegram Трекер Бот
Задача
Telegram бот (Python, aiogram 3.x, SQLite, httpx). Отслеживает Twitter аккаунты, шлёт алерты в личку юзера. Платная подписка через CryptoBot (TON/USDT). Реферальная система.

Тарифы
Starter $5/мес — 5 аккаунтов
Pro $10/мес — 10 аккаунтов
Business $15/мес — 15 аккаунтов
Триал: 1 день, 1 аккаунт (одноразово)
Структура файлов
text

bot.py — точка входа
config.py — .env
database.py — SQLite
keyboards.py — кнопки
handlers/ — start, subscription, tracking, filters, referral, admin, payment_callback
services/ — twitter, payment, tracker_worker, scheduler
БД (SQLite)
users: user_id PK, username, tier(null/starter/pro/business), subscription_until, trial_used, referred_by(user_id), balance(для рефералки), filter_retweets(bool default true), filter_replies(bool default true), banned(bool), created_at

tracking: id PK, user_id FK, twitter_username, last_tweet_id, UNIQUE(user_id, twitter_username)

payments: id PK, user_id FK, amount, currency(TON/USDT), tier, invoice_id, status(pending/paid/expired), created_at, paid_at

referrals: id PK, referrer_id FK, referred_id FK, payment_amount, commission(10%), created_at

.env
BOT_TOKEN, ADMIN_ID, CRYPTOBOT_TOKEN, TWITTER_AUTH_TOKEN, TWITTER_CT0, TWITTER_ACCOUNT_1_AUTH, TWITTER_ACCOUNT_1_CT0 (до 10 акков), PROXY(опционально), SUPPORT_USERNAME

Сценарии
/start (новый юзер)
"Привет! Трекаю Twitter→Telegram за секунды". Кнопки: [Триал 1 день] [Оформить подписку]. Если пришёл по ссылке t.me/bot?start=ref_123 — сохранить referred_by.

/start (с подпиской)
Главное меню: [Мои аккаунты (3/10)] [Фильтры] [Подписка] [Рефералка] [Помощь]

Мои аккаунты
Список + [Добавить] [Удалить]. Добавление: ввод @username, проверка существования через Twitter API, проверка лимита по тарифу. Удаление: inline кнопки с каждым аккаунтом.

Фильтры
Toggle кнопки: [Ретвиты: ВКЛ/ВЫКЛ] [Реплаи: ВКЛ/ВЫКЛ]. При нажатии меняет в БД и обновляет сообщение.

Подписка
Без активной: выбор тарифа → выбор валюты (TON/USDT). Баланс списывается автоматически, остаток через CryptoBot. Если баланс покрывает полностью — оплата без CryptoBot. С активной: инфо + [Продлить] [Повысить тариф]. Продление добавляет дни к текущей дате истечения (не к сегодня).

Рефералка
Показать ссылку t.me/bot?start=ref_{user_id}, статистику (приглашено/оплатили/заработано), баланс. Баланс используется ТОЛЬКО для оплаты подписки, вывода нет. 10% начисляется ПОСЛЕ успешной оплаты приглашённого.

Помощь
"Пиши: @{SUPPORT_USERNAME из .env}"

Забаненный юзер
На любое сообщение: "🚫 Аккаунт заблокирован." Ничего больше не показывать.

Админка (только ADMIN_ID)

/give @username 50 — выдать $50 на баланс
/ban @username — бан + удалить все tracking
/unban @username — разбан

Напоминания (scheduler, проверка каждый час)
За 3 дня: "Подписка истекает через 3 дня [Продлить]"
За 2 дня: "Осталось 2 дня [Продлить]"

Воркер отслеживания
Дедупликация
Если 10 юзеров следят за @elonmusk — делать 1 запрос, рассылать всем 10. Собирать уникальные цели из всех tracking записей активных (не забаненных, с подпиской) юзеров.

Динамический интервал
Формула: targets * 60 / (33 * available_accounts). Минимум 5 сек, максимум 60 сек. При rate limit всех аккаунтов — множитель до x2 (макс 120 сек). Когда аккаунты освобождаются — множитель плавно к 1.0.

Фильтрация
Перед отправкой юзеру проверять его filter_retweets и filter_replies. Если ретвит и filter_retweets=false — не отправлять.

Формат алертов
Посты: "📝 Новый пост от @username", Ретвиты: "🔄 Ретвит от @username", Реплаи: "💬 Ответ от @username". Текст + дата МСК + ссылка. Если есть фото — send_photo с caption.

Оплата через CryptoBot
API: https://pay.crypt.bot/api. Заголовок: Crypto-Pay-API-Token. createInvoice для создания счёта, getInvoices для проверки. При успешной оплате: активировать подписку + начислить 10% рефереру если есть.

Важные нюансы
Продление: добавлять дни к subscription_until, не к today
Рефералка: 10% начислять ПОСЛЕ оплаты, не при создании счёта
Бан: удалять tracking записи, не давать ничего делать
Триал: одноразово, проверять trial_used
Баланс: списывать первым при оплате, остаток через CryptoBot
Atomic: транзакции при начислении баланса
Лимит аккаунтов: проверять при добавлении по текущему tier
